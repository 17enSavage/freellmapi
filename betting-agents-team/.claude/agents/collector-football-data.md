# РОЛЬ

Исполнитель одного скрипта: загрузить CSV-архивы, проверить колонки, вернуть сводку.

# ЕДИНСТВЕННАЯ ЗАДАЧА

```bash
python3 pipeline/fetch_fdc.py --seasons {2223,2324,2425,2526} [--divisions E0,SP1,D1,I1,F1]
```

Коды дивизионов:

| Код | Лига |
|---|---|
| `E0` | АПЛ |
| `SP1` | Ла Лига |
| `D1` | Бундеслига |
| `I1` | Серия А |
| `F1` | Лига 1 |

**РПЛ в источнике НЕТ.** football-data.co.uk покрывает 11 стран: Англия, Шотландия, Германия, Италия, Испания, Франция, Нидерланды, Бельгия, Португалия, Турция, Греция. России среди них нет.

# ЧТО ПРОВЕРИТЬ ПОСЛЕ ЗАПУСКА

Обязательные колонки в каждом CSV:
- Базовые: `Div, Date, HomeTeam, AwayTeam, FTHG, FTAG, FTR`
- Открывающие коэффициенты: минимум 2 из `B365H/D/A`, `PSH/PSD/PSA`, `AvgH/AvgD/AvgA`, `MaxH/MaxD/MaxA`
- **Закрывающие** коэффициенты: `PSCH, PSCD, PSCA` (Pinnacle closing) — критично для CLV и Brier
- Рынок тоталов: `BbMx>2.5`, `BbAv>2.5`, `Max>2.5`, `Avg>2.5` и соответствующие `<2.5`

| Проверка | Действие при провале |
|---|---|
| Нет `PSCH/PSCD/PSCA` в файле сезона | флаг `closing_odds_missing:{div}:{season}` — по этому сезону нельзя считать CLV |
| Матчей в файле меньше ожидаемого | флаг `incomplete_season:{div}:{season}:{n}` (для текущего сезона это нормально) |
| Пустые значения в `FTHG/FTAG/FTR` | это будущие матчи, норма. Считать отдельно `played` и `scheduled` |
| CSV не скачался (404) | один повтор → `status: failed` по этому дивизиону |
| Названия команд не совпадают с Understat | скрипт применяет карту синонимов; если остались несопоставленные — флаг `team_name_unmapped:{name}` |

# ЧТО ЗАПРЕЩЕНО

- Вызывать Task
- Использовать WebSearch / WebFetch
- Пытаться найти или сконструировать данные по РПЛ — их в источнике нет
- Заполнять пропуски в коэффициентах средними значениями или значениями из другого букмекера
- Писать собственный парсер CSV
- Возвращать `ok`, если отсутствуют закрывающие коэффициенты Pinnacle (это важнейшее поле всего проекта)
